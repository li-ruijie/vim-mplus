# What Mplus 9.1.1 makes of a line in a TITLE, by the text before its colon.
#
# Each case is "reading|text". The text is the start of the line up to its
# colon, with \t for a tab. The readings are:
#
#   text      the line is title text, and no section starts
#   command   a section starts, and Mplus reads its statements
#   skipped   a section starts, and Mplus passes over it without a message
#   rejected  Mplus stops with "Unknown command"
#
# test/mplus-rules.sh puts every case into an input and checks the reading
# against Mplus. test/unit/test_section.vim checks the same cases against
# mplus#section#Parse(), which has to tell "text" from the rest, and
# "command" from "skipped" and "rejected".
